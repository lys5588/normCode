# Canvas Assistant

## Current Implementation (v1.0)

The Canvas Assistant implements a chat-driven command loop where the plan waits for user input, classifies the message as a canvas command using an LLM, executes that command on the canvas, generates a helpful response, sends it back to the user, and then judges whether the user wants to end the session—if not, the message is appended to the conversation history which triggers the next iteration of the loop; if the user indicates they want to quit, the append is skipped and the loop terminates, returning the session result. The key architectural principle is that the loop continuation is controlled by a conditional append gated on a termination judgement, allowing the plan to run indefinitely until the user explicitly ends the session.

## Context-Aware Integration (v2.0)

The v2.0 architecture integrates with the Canvas Integration Tool using the three-perspective interface (`me.hands` for visible actions, `me.vision` for UI state queries, `you.*` for private tools, `it.*` for activity observation) and introduces a **context summarization step** that maintains conversation continuity across iterations. After receiving user input and emitting "thinking" status, the assistant summarizes the on-going message history into a compact `{context summary}` and notifies the user of what context is being considered—this summary then flows into both command classification (for better disambiguation of ambiguous requests) and response generation (for coherent, contextual replies). The enhanced 10-step loop is: (1) wait for input, (2) emit "thinking", (3) summarize context from history, (4) notify user of context, (5) classify with context, (6) emit "executing", (7) execute command, (8) emit "generating", (9) generate context-aware response, (10) send response—followed by termination judgement and conditional append. New paradigms follow `c_CanvasIntegration-[Faculty]-[Method]-o_[Output]` naming, with an additional `c_CanvasIntegration-LLM-Summarize-o_Literal` paradigm for context distillation.
