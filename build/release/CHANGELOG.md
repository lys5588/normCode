# NormCode Canvas Changelog

All notable changes to NormCode Canvas will be documented in this file.
Changes are tracked from the `canvas_app/` directory.

---

## [1.0.5-alpha] - 2026-01-24

### Added
- Enhanced execution controller and WebSocket handling for improved task management
- Enhanced execution requests with agent profile fields and logging improvements


---

## [1.0.4-alpha] - 2026-01-XX

### Added
- Modal portals for improved rendering and styling
- Zoom controls and panel resizing in the canvas application
- File-based agent update endpoint and enhanced project configuration handling
- DirectoryBrowserModal and PathInput components for enhanced file navigation and upload functionality

---

## [1.0.3-alpha]

### Added
- Remote project management and execution features
- Server building functionality and logging enhancements
- Deployment schemas and UI for run management
- Repository tracking to portable schemas
- Remote execution support and unified architecture
- Enhanced logging and export functionality in PortableProjectService and UI

### Changed
- Refactored agent configuration to a tool-centric design
- Refactored project and agent configuration to support auto-discovery
- Enhanced agent management with project-aware configurations

---

## [1.0.2-alpha]

### Added
- Decoupled canvas app LLM from infra, using self-contained llm-settings.json

---

## [1.0.1-alpha]

### Changed
- Updated Windows build process and resource paths
- Enhanced UTF-8 support across the application

---

## [1.0.0]

### Added
- Initial NormCode Canvas application including backend, frontend, and comprehensive Windows build system
